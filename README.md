## 📌 About The Project

**End-to-End Frequent Flyer Portal (ENG-163087)** is a React-based web application designed for airline floor staff to manage frequent flyer accounts efficiently.

It replaces traditional paper records and Excel spreadsheets with an interactive digital interface where staff can search, add, edit, and delete flyer records.

The project focuses on usability, accessibility, form validation, asynchronous operations, and reliable error handling.

### 🌟 Why This Project?

- 📋 Simplifies frequent flyer account management.
- 🔍 Makes member records easier to search.
- ⚡ Provides instant feedback during user interactions.
- ♿ Supports accessible and keyboard-friendly navigation.
- 🛡️ Handles invalid inputs and simulated API failures.
